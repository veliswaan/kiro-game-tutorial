# Build Your First Web Game with Kiro

A hands-on tutorial for beginners to build their very own browser-based game using [Kiro IDE](https://kiro.dev), an AI-powered development assistant. This tutorial was created for the **AWS Summit Johannesburg · Student Zone**.

## 🎮 What You'll Build

A working browser game of your choice - Snake, Tic-Tac-Toe, Memory Match, Flappy Bird, Breakout, or your own idea! No prior coding experience required.

## 📖 View the Tutorial

View the tutorial as a [GitHub Pages](https://veliswaan.github.io/kiro-game-tutorial/) site if hosted.

## 🗺️ Tutorial Sections

1. **Welcome** - What you'll build and learn
2. **Part 1: Setting Up Kiro IDE** - Download, install, and configure Kiro
3. **Part 2: Build Your Game** - Choose a game type and use ready-to-use prompts
4. **Part 3: Enhance Your Game** - Add sound, high scores, difficulty levels, and more
5. **Part 4: Test and Polish** - Play your game and fix any bugs
6. **Part 5: Share Your Game on Builder Center** - Publish a blog post on [AWS Builder Center](https://builder.aws.com)

## 🛠️ What You Need

- A computer (Windows, Mac, or Linux)
- Internet connection
- [Kiro IDE](https://kiro.dev/download) (free to install)
- An [AWS Builder ID](https://builder.aws.com) (free, for publishing your blog post)

## 🌟 Key Features of This Tutorial

- **Self-paced** - Work through it at your own speed
- **Progressive disclosure** - Prompts hidden by default so you're not overwhelmed
- **Interactive game selection** - Click a game card to see the exact prompt to use
- **Complete workflow** - From setup to sharing your work with the world

## 🚀 Running Locally

Just open `index.html` in any modern web browser. No build step or server required.

```bash
# On Windows
start index.html

# On Mac
open index.html

# On Linux
xdg-open index.html
```

## 🌐 Hosting with GitHub Pages

To make this tutorial publicly accessible:

1. Push this repo to GitHub
2. Go to your repo's **Settings → Pages**
3. Under **Source**, select the `main` branch and `/ (root)` folder
4. Click **Save**
5. Your tutorial will be live at `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`
